# 审脉 AuditPilot 完整使用与演示指南

## 1. 启动

```powershell
cd D:\PycharmProjects（D盘）\intelligent-audit-system
.\.venv\Scripts\python.exe -m uvicorn web.main:app --host 127.0.0.1 --port 8000
```

访问 <http://127.0.0.1:8000>。首次启动会创建运行目录并加载种子审计知识。

## 2. 推荐演示顺序

### 2.1 工作台

打开 `/`，说明：

- 指标来自审计 Repository、整改任务、RAG Store 和 Skill Registry。
- 项目表支持搜索，ERP 等关键词会立即过滤。
- Agent 轨迹来自真实 Skill 运行日志。
- 控制健康、证据队列和交付就绪度由项目档案聚合。

### 2.2 创建审计项目

打开 `/audit`，选择 ERP 权限管理、ISO27001、高风险，补充业务背景、范围、期间、重点问题和已有证据，点击“运行 Agent 审计”。

观察：

1. 执行轨迹依次出现规划、检索、控制映射、风险评估和质量门。
2. 页面生成控制矩阵、审计程序、抽样计划、证据包、发现草稿和整改计划。
3. 项目被持久化，可在历史档案中重新打开。
4. 可以更新证据状态、控制测试结果和整改任务，再提交人工复核。
5. 报告和交付包可下载为 Markdown。

### 2.3 证据文件分析

在 `/audit` 上传 `.txt`、`.md`、`.csv`、`.tsv`、`.json` 或 `.log`：

- 文件不超过 5 MB。
- 系统输出字段画像、完整性、时间范围、异常与风险信号。
- 风险信号映射到控制，并生成补证建议。
- 分析记录可附加到选中的审计项目。

### 2.4 多 Agent 对话与记忆

打开 `/chat`，输入：

```text
请分析 ERP 权限日志证据、执行控制测试并生成整改计划
```

预期：

- 路由显示 `control_agent -> evidence_agent` 或相近协作结果。
- 右侧展示意图、置信度、工作记忆、情景记忆和画像字段。
- 第二轮可只说“继续检查上面的特权账号证据”，系统从持久化记忆恢复 ERP、权限和标准上下文。

### 2.5 知识库

在 `/knowledge`：

- 粘贴制度、标准、控制说明或底稿摘要并写入。
- 上传文本文件自动切块。
- 输入问题验证答案、来源、相关度和置信度。

推荐问题：

```text
SOX ITGC 变更管理需要哪些审批与测试证据？
```

### 2.6 Agent Runtime

在 `/skills` 创建 ERP 权限审计任务：

- 第一阶段自动执行，后续可逐步运行。
- 任务详情显示计划依赖、Agent 角色、工具调用、产物和反思。
- Skill 卡展示超时、缓存和熔断配置。
- 安全门禁可独立测试输入风险。
- MCP Tools 表展示工具描述、Schema 和权限。

### 2.7 评测与发布

在 `/training`：

- 运行 Agent 评测、RAG 评测或 Deep Research。
- 添加自定义问题、预期答案和关键词。
- 查看真实性、可操作性、专业性、工具轨迹和人工复核意识。
- 新运行会与同类型上一基线比较，下降超过阈值会阻断或要求复核。

## 4. 配置模式

- `AUDIT_DISABLE_LLM=1`：完全确定性模式。
- `DEEPSEEK_API_KEY` / `OPENAI_API_KEY`：启用兼容 OpenAI 协议的 LLM。
- `RAG_LIGHT_MODE=1`：轻量检索。
- MySQL、Neo4j 未配置时自动降级。

## 5. 常见问题

- 页面仍显示旧样式：强制刷新，模板已使用 `app.css?v=4.0.2` 缓存版本。
- 对话较慢：LLM 模式受网络与模型延迟影响；确定性模式更快。
- RAG 没有结果：先写入知识或检查 `data/rag_store/documents.json`。
- 评测被阻断：查看整体分数、通过率、回归数和与基线的差异。
- 端口占用：改用 `--port 8001`，同时更新访问地址。
