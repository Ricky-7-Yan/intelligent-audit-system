# v4.0 升级变更记录

## 1. 升级目标

- 学习 EchoMind 归档中成熟的 Agent 工程能力。
- 保留审脉原有审计行业特色。
- 对齐字节、腾讯、阿里 Agent 岗位的常见工程要求。
- 把界面从功能堆叠升级为清晰的企业产品。
- 用 Git 分阶段保存，确保可回退。

## 2. 后端升级

- 新增 `HybridIntentRouter`：可解释的 Pattern + n-gram 融合路由。
- 新增 `ConversationMemory`：工作、情景、画像和相关历史。
- `AuditAgent` 接入外部记忆，并在轨迹中记录 Memory 阶段。
- Runtime 新增步骤依赖、Agent 角色、重试预算、Reflection 和检查点指标。
- Skill Registry 新增 Schema 校验、超时、TTL 缓存、熔断和可靠性元数据。
- 评测 Repository 新增同类型基线差异、质量/延迟回归和发布门禁。
- 新增 Router、Memory API，健康检查升级到 v4.0.0。
- 新增自动化测试。

## 3. 前端升级

- 总览删除大段宣传式 Hero，改为项目优先的操作台。
- 新增项目表、全局搜索、Agent 轨迹、控制健康、证据队列和交付就绪度。
- 六个页面统一品牌、导航、术语、颜色和密度。
- 对话页显示路由意图、多 Agent、工作/情景/画像记忆。
- Runtime 页显示 Skill 超时、缓存、熔断、工具状态和 Reflection。
- 修复 390px 移动端横向溢出，导航可横向滚动且隐藏原生滚动条。
- 保留审脉深海军蓝 + 青绿色品牌，不复制 EchoMind 客服界面。

## 4. EchoMind 能力吸收清单

| EchoMind 能力 | 审脉 v4.0 |
| --- | --- |
| 三路意图识别思想 | Pattern + 本地 n-gram 融合路由，可后接 LLM |
| Redis + ChromaDB 三级记忆 | 可直接运行的文件三层记忆，预留生产迁移 |
| 多 Agent 路由 | 审计领域多 Agent 协作与角色计划 |
| Skills 热能力 | 受 Schema、权限、超时、缓存和熔断治理的 Skills |
| MCP 工具可靠性 | MCP 描述、调用日志、缓存、超时、熔断 |
| RAG 查询改写 | Agentic RAG 混合检索和来源引用 |
| Monitor 影响路由 | Runtime/Skill 观测，为动态路由提供指标基础 |
| LLM-as-Judge 回归 | 多维评测、基线差异和发布门禁 |

## 5. 保留的原有特色

- COBIT、ISO27001、SOX、数据安全法控制库。
- 审计证据文件分析与控制映射。
- 审计程序、抽样计划、底稿索引。
- 风险评分、证据质量门和人工复核。
- 审计发现、整改任务、关闭状态和交付包。
- MySQL、Neo4j、LLM 均可选，离线降级仍可运行。
