## 02 本轮新增能力

### 2.1 运行时页信息架构升级

- 将 `/skills` 从长滚动页面升级为控制台分区：
  - 总览
  - Harness
  - 任务
  - 工具
  - MCP
  - 日志
- 所有主要 section 支持页面快速导航与折叠，解决“东西多、下拉很长、看不过来”的问题。
- 任务队列和日志区使用内部滚动，避免整页被长列表拖垮。

### 2.2 Self-Evolution Control Plane

新增可视化模块：

- 自进化成熟度
- 市场趋势覆盖率
- Benchmark Backlog 数量
- 自进化提案数量
- 市场关注方向雷达
- Benchmark Backlog 列表
- 自进化提案卡片
- Observe → Mine Weakness → Propose → Validate → Ship/Rollback 控制平面

### 2.3 提案物化为运行时任务

页面按钮会调用：

```http
POST /api/agent/evolution/proposals/{proposal_id}/task
```

生成的任务进入 `AgentRuntime`，并保留：

- task id
- plan
- tool calls
- artifacts
- reflections
- safety gate
- metrics

这让“自进化”不只是看板，而是可以进入项目执行链路。

### 2.4 记录治理与长列表收口

- 评测历史、审计档案历史、证据分析历史改为折叠记录。
- 新增 `DELETE /api/evaluation/runs/{run_id}`、`DELETE /api/audit/runs/{run_id}`、`DELETE /api/evidence/analyses/{analysis_id}`。
- 前端提供“打开 / 删除”明确动作，删除当前打开记录时同步清空相关结果和下载链接。
- 评测历史、审计历史、证据分析历史、证据请求、控制测试、整改任务增加局部滚动，减少整页长下拉。
- 新增专项文档 `docs/13-记录治理与界面收口升级.md`。

## 03 JD 与市场趋势对应关系

| 市场 / JD 方向 | 本项目对应能力 | 下一步增强 |
| --- | --- | --- |
| Harness / Sandbox | AgentRuntime、SafetyGate、Skill Registry、EvolutionHarness | 引入更真实的隔离 worker 和预算控制 |
| AgentOps / Observability | 运行时指标、Skill run、evaluation runs、release gate | 更细粒度 trace 与失败自动聚类 |
| MCP / Tool Use | MCP-style tool schema、权限注解、缓存、熔断 | 接入真实 MCP server 并记录 tool selection precision |
| 多 Agent 协作 | intent router、agent role、runtime plan、verifier | role-level trace 可单独评分 |
| 自进化 / Experience Unit | ConversationMemory、benchmark backlog、proposal materialization | 经验单元评分、过期策略、冲突检测 |
| 端到端评测 | Agent eval、RAG eval、Deep Research eval、release gate | AgentBench / GAIA / TAU-bench 风格样例扩展 |
| 行业可交付工作台 | 审计项目、证据分析、控制测试、整改闭环、交付包 | 真实企业系统连接器与项目组合视图 |

1. 继续检查页面是否存在文字重叠、拥挤、不可读。
