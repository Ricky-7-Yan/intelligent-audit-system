## 3. 高频考点归纳

### 3.1 Agent / 大模型应用

- Agent 与普通 LLM Chat 的区别：是否有目标分解、工具调用、状态管理、错误恢复、评测闭环。
- Planning 如何做：静态模板、动态规划、DAG、状态机、ReAct、Plan-and-Execute 的取舍。
- Memory 如何做：短期上下文、历史摘要、用户画像、业务实体记忆、向量召回和隐私边界。
- Tool Use 如何保证可靠：Schema、权限、幂等、超时、重试、缓存、熔断、日志、人工确认。
- Multi-Agent 如何避免堆概念：按角色职责和产物拆分，由统一质量门收敛，而不是多个 Agent 随机聊天。

### 3.2 RAG / Deep Research

- 文档切块：按结构、段落、滑窗、语义边界；为什么不能只按固定长度切。
- 召回：关键词、BM25/TF-IDF、向量、混合检索、查询改写、多路召回。
- 重排：Cross Encoder、LLM rerank、规则重排；何时不值得引入。
- 幻觉控制：答案必须绑定来源；证据不足时输出缺口，而不是编造结论。
- 评测：相关性、忠实度、引用覆盖、答案完整性、延迟、失败模式分类。

### 3.3 工程与系统设计

- API 设计：请求模型、响应结构、错误码、幂等、分页、下载接口。
- 数据层：文件 Repository 适合演示和轻量部署；生产可以迁移到 MySQL/PostgreSQL + 对象存储。
- 性能：缓存、预热、并行评测、增量评测、异步任务、前端状态反馈。
- 可观测：运行日志、trace、metrics、badcase、版本差异和回归检测。
- 安全：工具权限、敏感输入检查、上传限制、人审门禁、审计日志。
